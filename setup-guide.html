🚀 KOL Panel — Setup Guide

Panduan lengkap menyiapkan extension, Google Sheets, dan Apps Script
1 Load Extension di Chrome ✓ SUDAH JADI

Status: Extension sudah diload di chrome://extensions.

Verifikasi:

  • Buka chrome://extensions
  • Cari "KOL Panel" dalam daftar
  • Pastikan toggle ON (biru)
✓ Jika melihat icon KOL Panel di kanan address bar, lanjut ke Step 2.
2 Setup Google Sheets & Apps Script → MULAI DI SINI

Tujuan: Buat spreadsheet baru dan deploy Apps Script sebagai Web App.

2a. Buat Spreadsheet Baru

  1. Buka sheets.new — ini akan membuat spreadsheet kosong
  2. Beri nama: "KOL Panel" (atau apa saja yang kamu suka)

2b. Setup Apps Script

  1. Di spreadsheet yang baru, klik Extensions → Apps Script
  2. Akan terbuka tab baru ke editor Apps Script
  3. Hapus file Code.gs yang bawaan (select semua, delete)
  4. Buat file baru untuk setiap file di folder apps-script/ repo:
    • Config.gs
    • Logic.gs
    • Code.gs
    • SheetSetup.gs
  5. Untuk setiap file:
    • Klik + (plus icon) → File
    • Beri nama file (tanpa .gs)
    • Copy-paste isi file dari repo ke editor
    • Tekan Ctrl+S untuk simpan
  6. Setelah semua 4 file ada, kembali ke spreadsheet dan refresh halaman (F5)
💡 Tip: Jangan copy-paste error — verifikasi setiap file punya baris pertama yang benar.

2c. Jalankan Setup Sheets

  1. Di spreadsheet, tunggu ~5 detik sampai menu baru muncul
  2. Klik KOL Panel → Setup Sheets
  3. Akan muncul dialog. Klik OK atau Continue
  4. Tunggu sebentar... spreadsheet akan otomatis membuat 6 sheet baru:
  5. KOL, Post, Campaign, Kalender, Dashboard, Config
✓ Jika melihat 6 sheet baru di tab bawah, lanjut ke 2d.

2d. Deploy sebagai Web App

  1. Di editor Apps Script, klik Deploy → New deployment
  2. Pilih tipe: Web app
  3. Isi:
    • Execute as: Pilih email kamu (biasanya sudah terpilih)
    • Who has access: Pilih Anyone
  4. Klik Deploy
  5. Akan muncul URL panjang. Copy URL itu dan simpan di tempat aman
✓ URL Web App sudah di tangan. Lanjut ke Step 3.
3 Ambil Token dari Sheets

Tujuan: Copy token otomatis yang sudah digenerate Apps Script.

  1. Di spreadsheet, buka sheet Config (tab paling kanan)
  2. Kamu akan lihat dua kolom: Key dan Value
  3. Cari baris dengan Key = "Token"
  4. Di kolom Value, ada string panjang yang acak — copy itu
✓ Token sudah dicopy. Sekarang kamu punya:
  • ✓ Web App URL
  • ✓ Token
4 Configure Extension Settings

Tujuan: Beri tahu extension di mana Web App-nya dan token apa yang dipakai.

  1. Di browser, cari icon KOL Panel (di kanan address bar)
  2. Klik icon → akan muncul popup kecil
  3. Klik ⚙️ Options atau Pengaturan (sesuai browser language)
  4. Halaman pengaturan terbuka. Isi form dengan:
  5. Web App URL: Paste URL dari Step 2d
    Token: Paste token dari Step 3
  6. Klik tombol Tes koneksi
🔍 Cek koneksi:
  • Hijau "Koneksi berhasil" → Lanjut ke Step 5 ✓
  • Merah "Koneksi gagal" → Verifikasi URL dan Token (lihat troubleshooting di bawah)

Klik Simpan pengaturan untuk selesai.

5 Test di Browser

Tujuan: Verifikasi semuanya jalan dengan navigasi ke profil asli.

  1. Buka salah satu situs (pilih satu):
    • TikTok: @nasa
    • Instagram: @nasa
    • Threads: @zuck
  2. Tunggu halaman fully load (biarkan selama 3-5 detik)
  3. Lihat di kanan atas halaman — ada panel "KOL Panel" dengan:
    • Nama akun + follower count
    • ER (Engagement Rate)
    • Posting rhythm
    • Tombol "Kirim ke Sheets"
✓ Panel muncul = extension berfungsi!

5b. Kirim Data ke Sheets

  1. Klik tombol "Kirim ke Sheets" di panel
  2. Tunggu konfirmasi (seharusnya hijau "Tersimpan")
  3. Buka spreadsheet KOL Panel → sheet KOL
  4. Seharusnya ada baris baru dengan data profil (nama, followers, ER, dll)
✓ Data muncul di Sheets = semuanya berhasil! 🎉

🔧 Troubleshooting

❌ Panel tidak muncul di halaman profil

  • Cek 1: Refresh halaman (F5)
  • Cek 2: Chrome > Extensions > KOL Panel toggle ON?
  • Cek 3: Cek Console (F12 > Console tab) untuk error merah

❌ "Koneksi gagal" saat tes koneksi

  • Penyebab 1: URL salah. Paste ulang dari Step 2d (harus cocok persis)
  • Penyebab 2: Token salah. Paste ulang dari Step 3
  • Penyebab 3: Apps Script belum di-deploy sebagai Web App. Ulangi Step 2d

❌ "Sheet ... tidak ditemukan"

  • Solusi: Jalankan KOL Panel > Setup Sheets lagi

❌ Panel muncul tapi data tidak loading ("belum ada post")

  • Normal jika profil punya sedikit post (perlu ≥2 post untuk menghitung statistics)
  • Coba profil lain yang punya lebih banyak post

✨ Setup Selesai

  • Klik "Kirim ke Sheets" untuk simpan data
  • Lihat Dashboard di Sheets untuk analytics
