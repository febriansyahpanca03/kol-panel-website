How to paste into extension:
  1. Click KOL Panel icon in address bar
  2. Click ⚙️ Options
  3. Paste Web App URL into first field
  4. Paste Token into second field
  5. Click Test Connection
  6. Should show green "Connection successful" ✓
If "Connection failed":
  • Verify Web App URL is correct (copy from Apps Script URL bar)
  • Verify Token has no extra spaces or characters
  • Check that Apps Script is deployed (should have deployment ID in URL)
  • Verify "Who has access" is set to "Anyone" in Web App settings
