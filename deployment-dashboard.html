❓ FAQ

Q: What do I need to do right now?

A: Follow SETUP_GUIDE.html (Step 2-4). This creates a Google Sheet, deploys Apps Script as a Web App, and configures the extension to use it. Estimated time: 15-20 minutes.

Q: Will it work without setting up Google Sheets?

A: The extension will load and show a panel with profile data. But "Kirim ke Sheets" (send to Sheets) won't work — you need the Web App URL and token. Local data only stores follower history, not profiles.

Q: Why do I need to capture real data?

A: The current parser fixtures are synthetic (based on public API structure docs). To be sure the parser works correctly with real-world data, we need 1-2 real API captures per platform. See CAPTURE_REAL_DATA.md (user-friendly) or FIXTURE_CAPTURE_GUIDE.md (technical).

Q: Is my data safe?

A: Yes. The extension runs entirely in your browser (offline-first). It only sends public profile data you're viewing + follower history (stored locally in chrome.storage). Your token is stored locally, never leaves your computer except for API calls to your own Google Sheet.

Q: What if the setup fails?

A: See the "Troubleshooting" section in SETUP_GUIDE.html. Most issues are URL/token mismatches. Check that you copied the Web App URL and token correctly, with no extra spaces.

Q: When can I release this to users?

A: After Steps 5-8 (real captures, security review, manual QA on each platform). Expected: 1-2 weeks if captures come in quickly. See TODO.md for the full pre-release checklist.
