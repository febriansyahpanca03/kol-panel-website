Ringkas: alur setup

  1. Buat Google Sheet baru lewat sheets.new.
  2. Salin empat berkas Apps Script (Code.gs, Logic.gs, Config.gs, SheetSetup.gs), lalu jalankan KOL Panel → Setup Sheets.
  3. Deploy sebagai Web App dengan akses Anyone, simpan URL-nya.
  4. Ambil token dari sheet Config.
  5. Tempel URL + token di halaman Options ekstensi, klik Tes koneksi.
  6. Buka profil TikTok/Instagram/Threads — panel muncul, klik Kirim ke Sheets.
